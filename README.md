A lightweight, privacy-focused web tool designed to decode Wi-Fi QR codes and display network names and passwords in a clear, readable format.

Key Features:
- Scan QR codes using a camera or upload images.
- Decode Wi-Fi credentials instantly.
- Generate shareable Wi-Fi QR codes.
- Save network details locally for quick access.
- Support offline usage after the first load.
- Ensure privacy with client-side processing and no server uploads.
- Responsive design with light and dark themes.

Tech Stack: HTML, CSS, JavaScript, jsQR, qrcode-generator

Deployment: GitHub Pages
